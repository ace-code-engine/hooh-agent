# 把 frontend/ TUI 当作 GUI 来写 — 三轨优化方案

**目标**:在瑞士风格规范(硬约束)之内,给主 TUI 补齐 GUI 级体验:①鼠标/触摸板完整交互 ②浮层窗口系统 ③动画与微交互。只动 `frontend/`,不改引擎协议、不动 Python `ui/` 冻结面、vendored 内核 135 文件零字节改动、不加新依赖。

---

## Phase 0 — 地基:门面扩容 + 全局鼠标 + 动画基建

1. **扩门面**(`vendor/dsh-ink/kernel.js` + `kernel.d.ts`,项目自有文件):
   - `kernel.d.ts` 的 `Box` 类型补上运行时已支持的鼠标/焦点 props:`onClick / onWheel / onMouseEnter / onMouseLeave / onContextMenu / onDragStart / onDragMove / onDragEnd / onFocus / onBlur / onKeyDown / tabIndex / autoFocus`
   - `kernel.js` 转口动画与测量内部件(沿用内核内部 specifier 大小写):`useAnimationFrame`、`useInterval`、`ClockProvider`、`measureElement`
2. **主屏鼠标启用**:新建 `src/tui/mouse-tracking.tsx` —— 常挂组件,仿 `AlternateScreen` 的 `useInsertionEffect` 写法,经 `TerminalWriteContext` 写 `ENABLE_MOUSE_TRACKING`(1000/1002/1003+1006 SGR),卸载时 DISABLE。已验证内核分发不门控备用屏。
   - 逃生口:沿用内核 `DSH_TUI_DISABLE_MOUSE=1`(关点击保滚轮),新增 `ACE_NO_MOUSE=1` 完全关闭(恢复终端原生选择)
   - **spike 风险项**:挂起/复焦后模式重断言(app.js:452 已有重断言机制,验证覆盖面;不足则监听内核 `terminalfocus` 事件自行重断言)
   - 主屏原生文本选择与鼠标模式的冲突:文档化 Shift+拖拽 原生选择逃生口
3. **动画基建**:新建 `src/tui/motion.tsx` —— `useReducedMotion()`(统一 `ACE_REDUCE_MOTION=1`,Spinner 已在用)+ 帧预算常量(上限 5Hz / 200ms 帧 / 浮层过渡 2 步 ≤250ms),全部走共享时钟。

## Phase 1 — 鼠标完整交互

1. **ScrollBox 滚轮**(`tui/scroll-box.tsx`):内容 Box 挂 `onWheel`(内核位置优先路由,指针在转录区才消费),滚轮翻动沿用既有 follow-tail/detach/refollow 三态语义——顺手了结代码注释里明记的"拿不到鼠标滚轮"欠账。滚动条槽点击=翻页、拖拽滑块=滚动(`onDrag*`)。
2. **可点行原语**(`design-system/primitives.tsx` 新增 `ClickableRow`):hover 即时反白高亮(反白=规范五工具之一)+ 点击,键盘等价动作保持。逐组件接入:
   - Picker / PrefPicker(选项点击=确认)
   - Input 斜杠菜单候选(点击=插入)
   - Home 行(点击=执行该行动作,复用既有命令)
   - PermissionDialog / ChoiceDialog(点击选项=作答;Esc=拒绝硬契约不动)
   - SettingsPanel 行、SessionTree 节点(点击=切分支)、HelpOverlay 条目、wizards 按钮
   - ToolCard(点击头部=展开/收起预览,纯前端状态)
3. **提示文案**:状态/帮助处补"点击或 ↑↓"类提示 —— 新 i18n 键 ×3 语言(zh/en/ja,守卫测试自动覆盖)。
4. **对等原则**:每个鼠标动作必须有键盘等价物(KEYMAP 文档纪律)。

## Phase 2 — 浮层窗口系统

1. **Overlay 容器**(`design-system/overlay.tsx`):底部锚定(输入行上方)的浮层——绝对定位(内核 `hitTestWithOverlays` 按挂载逆序命中,z 序内建);瑞士视觉:上下整宽细线 + `▌` 强调条 + ALL-CAPS 标题,**无框无底色填充**;浮层打开时背景转录整体降为 text_3 灰(三灰阶之内,可断言);超高内容内部走 ScrollBox(带滚轮);Esc 关闭。
2. **面板迁移**(App.tsx 的 `Panel` 整屏切换 → 浮层,状态机不动):
   - `/resume` 与 `/permission` `/sandbox` `/net` `/effort` 选择器 → 浮层
   - `/tree` 会话树、`/config` 设置面板 → 浮层(内部滚动)
   - `?` 帮助 → 浮层
   - DraftEditor **保持全屏**(编辑器要最大空间)
   - 审批/选择框统一浮层视觉;审批压浮层之上的既有语义保留
3. **单浮层原则**:一次一层 + 审批/选择最上层(与今日 Panel 状态机一致,不做多叠层)。

## Phase 3 — 动画与微交互(≤5Hz)

1. Spinner 迁到共享时钟,帧率审计 ≤5Hz,reduced-motion 静帧(已有 prop,统一到 motion.tsx)。
2. 流式输出光标:活动流式时 `▌` 2Hz 脉冲;reduced-motion 静止。
3. hover 高亮**不加动画**(终端里即时即正确);选择确认后 200ms 单帧反白闪光再关浮层。
4. 浮层开合不做硬切:背景灰阶 2 步过渡(约 250ms,2 帧);reduced-motion 直接终帧。
5. ContextBar/进度条保持静态(动画无信息增量,记录决策)。

2. `tsc --noEmit` + `npm test` + 既有真实引擎集成测试全绿。
3. **真机人工清单**(Windows Terminal,你来过目):hover/点击/滚轮/浮层/动画逐项;cp936 回退字形核对(只用已验证过的 `▌ █ │ ▏`)。
4. **文档**:TUI-SWISS-SPEC 新增"交互层"节(鼠标语言/焦点/浮层规则/动效常量);KEYMAP 对照表加鼠标列;HANDOFF 更新。

## 主要风险与对策
- 主屏鼠标 vs 原生选择:Shift+拖拽文档化 + 双逃生口(Phase 0.2)
- 挂起/复焦模式丢失:spike 验证内核重断言,不足则 terminalfocus 自愈
- hover 引发转录全量重渲染:行组件局部 state,内核有节点测量缓存兜底
- 主屏绝对定位浮层与 inline 布局共存:Phase 2 首日先做 spike 验证 hitTestWithOverlays 实测
