# HooH v1.1.0 —— 界面重做：一份规范、一个主面、三语成套

> 面向用户。发布说明索引见 [docs/README.md](../README.md)；完整条目见 [CHANGELOG.md](../../CHANGELOG.md)。

## 一句话

把界面从"**两个面各画一套**、框线 + 多色相"收敛成"**一份规范、一个主面、两个面同源**"——
统一到瑞士主义那套可断言的规矩上（左对齐、不画边框、一屏一个强调色、整宽细线），
并且**中/英/日三套文案成套**：切到哪种语言，斜杠后面的提示、对话框、报错、底栏全都跟着换。

顺带修掉一批你实际撞到的问题：回答出现两遍、`/fullscreen` 空转、召回历史后 LOGO 消失、
上下文窗口被写死成 32K、以及"测试跑一次就把你的配置覆盖掉"。

## 能摸到的新东西

| 面 | 你现在能做什么 |
|---|---|
| **上下文窗口跟着模型走** | DeepSeek 系自动按 **1M**、GLM-4.6/4.7 按 **200K** 算（表里只放核过官方出处的条目）；表外的模型走兜底 **并明确告诉你"窗口未知"**。新增 **`/window <tokens\|auto>`**：`/window 1m` 一条命令校正，裸敲显示当前值与**来源**（你设的 / 已知表 / 未知兜底）。换模型自动重算 |
| **界面语言 = 界面语言** | `/lang zh\|en\|ja` 只管**界面**（此前它顺手把"回答用什么语言"也改了 —— 而这个项目的初衷恰恰是中文界面 + 中文提示词）。切语言时引擎发 `language` 事件，前端跟着换字典，**斜杠后面的那串提示不会半中半英** |
| **全屏会话真能用** | `hooh --fullscreen`（或 `ace.cmd --fullscreen`，入口本来就 `%*` 透传）。全屏里转录有自己的**滚动视口**：`PgUp/PgDn`、`↑/↓`、`g`/`G` 翻，右侧自动出滚动条，往上翻多久都不会蹦回底部 |
| **不闪了** | ①主屏转录用 `<Static>` 写进**终端真实回滚缓冲**（写完就不再重画）；②全屏与主屏的每帧写入都包**同步输出**（`?2026`）—— 长转录按 `/` 弹菜单不再频闪。不认识该序列的终端会自动忽略，零兼容风险 |
| **边角零件统一了** | 新增一层设计系统：分隔线（整宽、标题可居中嵌进线里）、状态图标（六态 `✓ ✗ ⚠ ℹ ○ ◌`）、进度条（**八分之一块** `▏▎▍▌▋▊▉█`，半格也算得出）、byline、快捷键提示、列表项、面板、页签、对话框外壳。**每一条都与终端侧逐值对拍**，不许"同一个零件两种长相" |
| **首屏会看你的"思考强度"** | 方块小人按强度摆姿势：`low` 蹲着、`high/max` 举臂、`auto` 站着；思考行带 `∴` 与强度符号（`∴ 思考中 ◉`） |

## 命令新增

| 命令 | 作用 |
|---|---|
| `/window [tokens\|auto]` | 看/改上下文窗口（`/window 1m`、`/window 200k`、`/window auto`）。裸敲显示当前值与来源 |

## 修掉的真问题

- **回答输出两遍**：被格式守卫拒掉的草稿没清，且工具时间线（`⚙ 2 次工具调用`）夹在流式增量与收尾之间时，合并逻辑只认"最后一条"→ 整段回答又推一次。两处都修了。
- **`/fullscreen` 是空转**：引擎改了配置，但 `config.request` 的 payload 里**根本没有这个字段**，前端无从知晓。现在这条路通了。
- **召回历史后 LOGO 没了、往上翻也翻不动**：进聊天时有一句"清屏"（`\x1b[2J`），它会把**终端回滚缓冲一起清掉** —— 首屏那张卡和刚打过的 `/resume` 预览全被抹了。删掉。
- **`/vim on` 之后输入框"废了"**：vim 普通模式会吃掉所有按键（含 `/`），而界面上没有模式提示。现在输入行右侧有模式小标。
- **测试会覆盖开发者的配置**：跑一次全量测试，子进程会把 `~/.ai_code.json` 写成测试用的空壳（`model=m1`、密钥全空、`project_root` 指向临时目录）。现在有 `ACE_NO_SAVE_CONFIG=1` 闸门 + 一条"真实配置哈希不许变"的断言。
- **界面文案漏翻译**：渲染错误边界那两句中文是写死在 JSX 里的，三语字典再全也救不了。现在**代码里不许出现硬编码中文**（`frontend/test/i18n-complete.test.ts` 守）。

## 怎么试

```bash
python ai_code.py --mock          # 离线演示：首屏、方块小人、菜单、工具卡
python ai_code.py                 # 真模型（配置向导）
python ai_code.py --fullscreen    # 备用屏全屏：PgUp/PgDn/↑↓/g/G 翻，右侧滚动条
/window 1m                        # 把窗口校正成 1M（你的模型真支持的话）
/lang en                          # 切英文：斜杠菜单、对话框、报错一起换
```
