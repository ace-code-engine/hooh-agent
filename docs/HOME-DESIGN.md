# 主页设计（v3.39.0）

> 这份文档回答的是"为什么这样排"，不是"有哪些功能"。功能清单在 `/help` 与
> `docs/KEYMAP-CLAUDE-PARITY.md`；这里只讲**顺序与取舍**，因为那才是有争议的部分。

## 一、主页要回答的三个问题，按顺序

```
① 接着干什么      继续上次（时间 + 轮数）· 新对话 · 历史对话（n 条）· 命令与键位
② 现在是什么状态   思考强度 · 联网思考 · 界面语言 · 权限档 · 模型
③ 我们独有的在哪儿 回溯（n 个快照）· 任务树与改动 · 本轮报告
```

顺序的理由：

1. **"继续"排第一**：绝大多数人打开它就是想接着上次说。把它压到下面，等于每次都要
   先扫一遍别的信息；
2. **"能力开关"排第二**：它们必须在**开始之前**定好 —— 跑到一半才发现"我刚才该开高强度"
   就得重来。所以它们不能塞进某个二级菜单；
3. **"特色"排最后**：回溯/任务/报告是"需要时才找"的东西。常驻在眼前只会挤掉前两类，
   而前两类是每次都用的。

## 二、每个位置放什么（以及为什么不是别处）

| 位置 | 放什么 | 为什么不是别处 |
| --- | --- | --- |
| 顶行 | 版本 · 模型 · 权限（沙箱非 `off` 才露面） | 这三件事是"一眼要确认"的；其余状态归底栏 —— 主页不该是仪表盘 |
| 每行右侧 | **当前值**（`联网 开` / `思考强度 中` / `权限 readonly`） | 主页一半的价值在"现在是什么"。只写"联网思考"而不写当前状态，用户还得去别处查 |
| 行尾括注 | **怎么改**（`Alt+W 切换` / `Shift+Tab`） | 发现成本要为零：看到这一行就知道按哪个键 |
| 分区标题 | 中文短句，不用图标 | 图标在旧 conhost 里会渲染成方框（这条踩过） |
| 底部 | 一行提示：`↑↓ 选 · 回车执行 · 也可以直接在下面打字` | 主页是可操作的，得有人告诉用户"这里能用键盘" |

## 三、主页放在哪里：会话区的第一块，不是独立全屏页

- 独立页要"进去—出来"两次切换，滚动位置还会丢；
- 做成**会话区的第一块**：进来先看见它，打字/回车之后它自然滚上去 —— 这正好表达
  "聊天记录是主线，主页只是开场"。上游也是这么做的（把它当成消息列表的第 0 行，
  并且只在"没有消息"时渲染）。
- 想再看一眼：`Alt+1` 或 `/home` 再打一遍（不切换屏幕）。

## 四、能力开关的具体取舍

| 开关 | 档位 | 键 | 落在哪里 |
| --- | --- | --- | --- |
| 思考强度 | `auto` → `low` → `medium` → `high` | `Alt+T` / `/effort` | 系统提示增量（[`core/ace_effort.py`](../core/ace_effort.py)） |
| 联网思考 | 开 / 关 | `Alt+W` / `/net` | 提示词里加"先搜再答 + 列来源 + 当前年月" |
| 界面语言 | 中文 / English / 日本語 | `Alt+L` / `/lang` | 提示词里加语言段（**界面语言一起切**） |
| 权限档 | readonly → write → full | `Shift+Tab` / `/permission` | 执行层（进 `full` 需二次确认） |
| 模型 | 任意 | `Alt+M` / `/model` | 选择框（可输入过滤） |

三处设计决定值得单独说：

1. **`auto` 是默认档，且不加任何提示词**：默认行为不该被我们的偏好污染。用户没要求
   "多想一会儿"时，我们不替他加话。
2. **关键词逃生门**：输入里写 `ultrathink` / `认真想` → **这一轮**按最高档走，用完即清。
   零 UI 成本：想让它多想一会儿时敲一个词就行，不必先去改设置。
3. **语言只给一个开关**：界面上说"用英文回答"的人，几乎总是也想让界面说英文。
   拆成两个旋钮的结果是"模型说英文、界面说中文"这种半拉状态。

## 五、回溯：两段式（先选回到哪，再选退什么）

```
Esc Esc（空输入）
  ├─ 第一段：从最近的输入里选"回到哪一条"（可输入过滤）
  └─ 第二段：退什么 —— 退对话并回退文件 / 只退对话 / 只回退文件到最近快照 / 算了
```

- **为什么分两段**：`退对话两轮` 和 `回退文件到快照 3` 是两类无法比较的东西，并排在一个
  列表里只能靠读完整句判断。分开之后每一步都只有一类东西可比。
- **能力门控**：没有快照就**不显示**"回退文件"那一项（给了也只会报错）。
- **默认选项是最完整的那个**（退对话 + 回退文件），但**取消永远在**（`算了，不回退`）。

## 六、还没做的（写清楚，免得看着像忘了）

- 会话列表目前是"每条一行、时间靠 mtime"，上游那种"两行 + 固定序元数据（时间 · 分支 · 体积/条数 · 标签）"
  还没做全 —— 分支与体积我们没采集；
- 历史里的"摘要到某处"（把中间段折叠成摘要）没做：那要动压缩链路，单独评估；
- 首屏还缺"首次运行的向导"（上游是一张条件式步骤表：认证 → 主题 → 安全 → 终端设置）。
  我们的 `setup_env.py` 顶了其中一半，剩下的等有真实需求再加。
