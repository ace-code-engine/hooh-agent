### 结论 / 约定
- 前端 i18n 沿用**组件局部三语字典 + 反引号/JSON/`export {}` 规避守卫**的既有惯例
  （help/、usage/ 是先例）。`locales/**` 与 `i18n-complete.test.ts` 归「整合波」独占，
  需用户批准后才动 —— 本次未做整合。
- 本地 `design-system.test.tsx` / `status-parity.test.ts` 的
  `spawnSync C:\aider_env\Scripts\python.exe EBUSY` 是 Windows 本机特有问题
  （该 exe 存在但被占用）；CI ubuntu 走 `/usr/bin/python3`，不受影响。
- 本地验证口径：`ruff check . --select E9,F63,F7,F82,F401,F841,E711,F811` 零命中；
  `npm run build`(tsc --noEmit) 通过；`npm test` 510 passed / 0 failed（4 skipped）；
  `python demo/record_demo.py --check` 四图全过。
- 环境备忘：pip 直连 PyPI 不通，清华镜像可用；ruff 需下 wheel 手动装
  （`pip install ruff` 报 "from versions: none"）。本地 `npm ci` 被 safe-delete 拦，
  用 `npm install` 绕过（注意它会改 package-lock.json，完事要 `git checkout --` 还原）。
